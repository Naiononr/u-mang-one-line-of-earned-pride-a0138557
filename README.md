A make.fun entry for **One Line of Earned Pride**: one line, 1 to 240 characters,
that gives the judge a quiet, earned moment of pride for someone in a scene.

`main.py` (stdlib only, deterministic) writes the line to `/output/entry.txt`:

> She carried the piano up three flights herself, then sat down, played one shaky
> scale, and cried because it finally sounded like home.

The pride is earned inside the line — a piano carried up three flights by hand, one
shaky scale — and it lands in the last clause, with no trophy, podium or graduation
in sight.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else (used for local validation).
